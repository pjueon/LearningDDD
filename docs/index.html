처음부터 읽기

이 교재는 이렇게 생겼습니다

한 장(chapter)은 여러 개의 페이지으로 나뉩니다. 페이지는 ← → 방향키나 아래쪽 버튼으로 넘깁니다. 어디까지 읽었는지는 이 브라우저에 저장되므로, 다음에 다시 열면 이어서 읽기가 나타납니다.

읽는 방법

  • 접힌 상자는 눌러서 펼치는 부분입니다. 더 깊이는 처음 읽을 때 건너뛰어도 되고, 모범답안은 스스로 해본 다음에 열어보세요.
  • 퀴즈는 반드시 풀어보세요. 해설에 본문에 없는 이야기가 들어 있습니다.
  • 점선 밑줄이 그어진 SKU 같은 낱말은 마우스를 올리면 뜻이 나옵니다.
  • Before / After 탭이 있는 코드는 탭을 눌러 나쁜 코드와 고친 코드를 같은 자리에서 비교해 보세요.

학습 트랙 — 하나 골라서 시작하세요

전체 분량은 178페이지 / 약 32.5시간입니다. 읽기만 하는 시간이 아니라 퀴즈와 "직접 해보기" 과제까지 포함한 시간입니다.

어떤 트랙이든

3장(애그리게이트)·7장(도메인 이벤트)·9장(바운디드 컨텍스트)에서는 속도를 늦추세요. 이 세 장이 DDD의 허리이고, 나머지 장은 대부분 이 셋의 응용입니다.

목차

    이 교재를 다 읽으면

    1. 트랜잭션 스크립트로 짠 코드의 문제를 지적하고 도메인 모델로 옮길 수 있습니다.
    2. 요구사항에서 Entity / Value Object를 구분하고, 애그리게이트 경계를 근거와 함께 그을 수 있습니다.
    3. 도메인 이벤트로 결합을 낮추고, 그 대가(결과적 일관성)를 설명할 수 있습니다.
    4. 시스템을 바운디드 컨텍스트로 쪼개고 컨텍스트 맵을 그릴 수 있습니다.
    5. DDD를 쓰지 말아야 할 상황을 판단할 수 있습니다.
