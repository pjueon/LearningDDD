# 도메인 주도 설계 첫걸음 — 한빛몰로 배우는 DDD

## 개요

도메인 주도 설계(DDD)의 핵심 개념을 예제를 통해 하나씩 이해할 수 있도록 구성한 학습 자료입니다.

이론을 나열하기보다, 가상의 온라인 쇼핑몰 "한빛몰"의 주문·재고·창고 업무를 따라가며 개념을 익히는 데 초점을 맞추고 있습니다. 장 하나는 HTML 파일 하나이고, 장 안은 페이지 단위로 넘겨 읽습니다. 코드는 Python입니다.

## 대상 독자

- 프로그래밍 경험은 있지만 DDD는 처음 접하는 개발자
- 소프트웨어 아키텍처(계층형, 헥사고날 등)를 처음 공부하는 사람
- 용어 암기가 아니라 "내 프로젝트에 DDD를 쓸지 말지" 스스로 판단할 수 있는 감각을 원하는 사람

## 시작하기

`docs/index.html` 파일을 브라우저로 열어서 읽으면 됩니다. 서버나 설치는 필요 없고 `file://`로 동작합니다.
페이지는 방향키(← →)나 아래쪽 버튼으로 넘기고, 읽은 위치는 그 브라우저에 저장됩니다.

## 읽는 트랙

| 트랙 | 속도 | 기간 |
|---|---|---|
| 여유 | 하루 30분, 매일(주 3.5시간) | 약 10주 |
| 표준(권장) | 평일 하루 1시간(주 5시간) | 약 7주 |
| 주말 집중 | 토·일 각 3시간(주 6시간) | 약 6주 |
| 단기 몰입 | 하루 2~3시간(주 12시간) | 약 3주 |

어떤 트랙이든 3장(애그리게이트), 7장(도메인 이벤트), 9장(바운디드 컨텍스트)에서는 속도를 늦추기를 권합니다. 트랙별 주차 계획은 `authoring/01-커리큘럼.md` §4에 있습니다.
