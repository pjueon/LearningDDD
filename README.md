# 도메인 주도 설계 첫걸음

## 개요

도메인 주도 설계(DDD)의 핵심 개념을 예제를 통해 하나씩 이해할 수 있도록 구성한 학습 자료입니다.

이론을 나열하기보다, 실제 예제를 따라가며 개념을 익히는 데 초점을 맞추고 있습니다.

## 대상 독자

- 프로그래밍 경험은 있지만 DDD는 처음 접하는 개발자
- 소프트웨어 아키텍처(계층형, 헥사고날 등)를 처음 공부하는 사람
- 용어 암기가 아니라 "내 프로젝트에 DDD를 쓸지 말지" 스스로 판단할 수 있는 감각을 원하는 사람

## 시작하기

`docs/index.html` 파일을 브라우저로 열어서 읽으면 됩니다.
